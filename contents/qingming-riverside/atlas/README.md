# atlas

`boat.webp` is a crop of `raw/overlays/boat.webp` at (40, 150, 2100×425), matching the upstream `scene.js` boat sprite extract. The ferry and the 虹桥过船 cargo overlay both scale it to ~213×64 world units (cargo also shrinks as it recedes under the arch).

Street-life pedestrians stay CSS silhouettes (`story/events/street-life.ts`). Upstream `people-ink.webp` / featured character sheets are **not** copied here — they live in gitignored `third_party/` and would be a later atlas crop, not this pack’s Phase F.
